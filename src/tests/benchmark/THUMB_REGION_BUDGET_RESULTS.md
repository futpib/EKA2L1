# One budget proof for each bounded Thumb path

Adopted: Sky Force improves in all four controlled pairs. Snakes is neutral with mixed pairs. The bounded fast path is now the default for eligible Thumb entries.

The compiler derives a conservative maximum guest instruction count over every path in a bounded Thumb body, including fused successors, call halfwords and folded veneers. One entry comparison selects a body with no internal budget exits. Short budgets use a private precise body. All path counts remain compile-time constants. This preserves existing timer boundaries, stop/IRQ behavior, callback state and SVC exits; it does not permit quantum overshoot. Cycles still end fusion. The implementation is generic and does not select game addresses.

## Native evidence and correctness

Retired native instructions fall 2.63% in Sky Force and 0.26% in Snakes. In warmed gameplay, caller 0x801a1044 shrinks from 11,072 to 8,256 native bytes and checks its bound of 22 once at entry. This is a code-size observation, not an instruction-throughput ratio. A separate metadata-enabled capture recovers all 160 selected code versions. Of 17,998 worker samples, 1,894 have exact ARM anchors and 1,502 exact C++ anchors; 13,628 have no instruction position, 512 are outside JIT code, and 462 lack a matching snapshot. Unmapped instructions are not assigned a source by interpolation. Short-budget bodies account for 58 worker samples. The normal timing artifact disables source metadata and was reproduced with all six hashes matching after restoring its embedded revision label.

The new proof passes 32,256 state/memory/callback chain comparisons and 3,808 independent DynCom comparisons. Both games pass exact 60-frame images, guest progress, audio events and PCM. The full suite initially reports 185 passes and one failure: an old veneer test required identical generated bytes even when the new entry wrapper was present. The test now checks the preserved precise body and executes partial-ROM cases against the original behavior. Its focused rerun passes 35,280 full-state veneer cases and 288 call-boundary cases. Runtime code did not change after the full run; the other 185 checks remain applicable. The pre-existing expected harness failure and diagnostics-only skips are retained in the logs. An executed-WASM fixture counter finds 864 lower, 224 equal and 256 higher paths out of 1,344; tiny budgets pay for a cold call, so this is not a claim that every path shrinks.
