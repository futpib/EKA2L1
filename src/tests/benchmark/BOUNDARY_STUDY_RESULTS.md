# Compiled-region boundaries and limits: measured findings

This study compares identical post-merge Snakes guest work within two routes: longer 42–60 guest seconds (3,031,637,220 instructions / 380 presentations) and standard 60–78 seconds (2,976,635,366 instructions / 381 presentations). It preserves ordinary memory/fault semantics, instruction budgets, interrupts and guest scheduling. The unsafe diagnostic is explicitly separated below. Measurements from older guest work or other CPU adapters are not pooled with these results.

## Boundary distinctions

A compiled-region return normally publishes guest state and re-enters lookup/validation/dispatch. Returning from the region runner is another boundary; raising its region-count cap does not retain values across separately compiled regions. Neither boundary by itself is a browser yield or a guest scheduling decision. A loop inside one small region can already repeat until its guest budget expires. Synchronous helpers can return directly, while budgets, interrupts, faults or invalidation can require intervention without JavaScript. The experiments do not change guest scheduling to hide compiler overhead.

All reports retain individual observations, actual ordering, configuration markers, hashes and relevant failures. Diagnostic elapsed times, requested byte coverage and synchronous module-constructor measurements are not substitutes for gameplay timings or physical traffic/total JIT compilation time. Exact replay checks observable execution on these routes; it does not establish immutable code or cross-game correctness. No result establishes globally optimal limits.

The delivered configuration uses conditional integer leaves with policy 7, a 512-byte hot source window, 16-instruction leaves, eight inlined sites and a 512-region runner cap. The user-directed rollout changes the executable-byte policy to full mode 3, retaining explicit mode 0 for compatibility. Later eligibility extensions remain off. The compiler-boundary and limit timings above used mode 0; their retained bounds have not been re-established as best under mode 3, where added dependency scans no longer cost execution time. No result establishes global optima. No push is part of this study.
