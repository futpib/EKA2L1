# Graduation and reassessment of marginal experiments

The user authorized graduating deferred memory exits and reassessing smaller
previous gains. Small repeatable improvements are eligible; a 1.25x realtime
milestone is not a minimum per-change acceptance threshold. Correctness,
regression risk, additional complexity and repeatability still matter.

## New experiments

Fresh comparisons use the graduated deferred-memory binary as the
baseline, physical NVIDIA graphics, real Snakes guest seconds 78–96, rendering
on and capture/profiling/counters off. One browser at a time including warmup.
All observations, including outliers, are retained.


### Fresh isolated variants

Both candidates pass 133 WASM tests, all three native targets, the full expanded
672-case production fault comparison (356 deferred cases), and a checked
1,600-image native-interpreter replay, including guest records, PCM and audio
events through 102.484363 guest seconds. The successor-cache regressions include
stale hints, replacement, address spaces, ARM/Thumb, remaps/unmaps and dependencies.
These were fresh candidate checks, not inferred from their older experiments.

No builds or correctness jobs overlap these measurements. Run order was
baseline/compact/successor/successor/compact/baseline, one browser at a time
including warmup. Host seconds for the same 18 guest seconds:

| Variant | Trials | Mean | Baseline / variant throughput |
| --- | ---: | ---: | ---: |
| Graduated deferred-memory baseline | 16.6192 / 16.8234 | 16.7213 | 1.000x |
| Plus compact memory | 17.0048 / 15.0995 | 16.05215 | 1.0417x |
| Plus guarded successor cache | 18.8893 / 16.1936 | 17.54145 | 0.9532x |

Successor caching does not earn promotion: its mean is worse and its range is
wide. Its prior roughly 1.7% mean improvement is not confirmed on the new baseline.
It is removed from the active source; its existing research patch and these raw
results remain. This does not prove every successor-linking design is slower.

Compact memory has a positive mean but a wide range. A separate confirmation batch follows. Small gains are eligible; favorable
selection of one run is not the criterion.


### Compact-memory confirmation

A fresh old/new/new/old batch against the graduated deferred-memory baseline:

| Build | Host seconds for 18 guest seconds | Mean |
| --- | ---: | ---: |
| Deferred exits | 18.5718 / 16.3794 | 17.4756 |
| Deferred exits + compact memory | 16.2864 / 15.5453 | 15.91585 |

Both candidate trials beat both controls in this batch. Throughput improves
**9.80% by the means**, versus **4.17%** in the first fresh batch. The candidate
reaches **1.1309x realtime** here, below the 1.25x milestone. These different
estimates reflect limited shared-host sampling; they are not additive and do
not establish a precise universal gain. Every run performs the same
3,975,200,506 guest instructions and 676 presentations.

The compact pattern uses an impossible cached-page key as the invalid sentinel.
A matching key proves that the cached base already passed permission/endian
validation, allowing two repeated base/host tests to disappear. Slow helpers
invalidate keys. Deferred misses preserve their pre-instruction exit; writeback,
PC and other non-deferred forms preserve the original helper contract. Zero-tag
permission checks, code-write tracking (when enabled), alias exits, budgets and
exact entry/dependency byte comparisons remain. It has no game/address whitelist.

The isolated two-minute live run passes manual upload/Start, keyboard/touch,
blur release, narrow layout, changing display and shutdown. It advances
**120.928852 guest seconds in 120.518953 host seconds** (**1.003401x** paced),
with **0.752765 seconds maximum sampled temporary lag**. Queue-delivery latency
is 0.89–4.01 ms, not display-response latency. Four intermediate captures show
active gameplay; one (60th sample) is black, followed by recovered gameplay at
samples 80/100 and the final nontrivial display. Its cause is unestablished;
this run does not establish flicker-free presentation or universally improved
smoothness. Paced catch-up is not an unpaced headroom estimate.

**Decision: graduate compact memory in addition to deferred exits.** It passes
the expanded correctness gates and gives positive means in two fresh game
batches on the graduated baseline. Small gains are accepted without requiring
that this one change reach 1.25x realtime. Keep successor caching removed; other
candidates retain the inventory decisions above. Earlier contradictory compact
results remain documented, and the limited shared-host evidence is not a
universal performance guarantee.

The final rebuild is byte-identical to the tested compact game, unit-test and
fault-probe WASM binaries. All three native targets pass after removing the
successor-cache experiment, and all seven frontend checks pass with installed
Chromium 153. The first frontend launch failed only because Puppeteer's expected
Chrome 146 was absent; rerunning with the actual installed executable passed.
The final game WASM hash is
`1c7084a27bd5df643f75787b5ce18e8ab7bae0c4359830ae4ac290be84c9683a`.

Reproduce the six-run comparison with `serial_variants.py ASSETS NEW_OUTPUT
baseline=ARCHIVE compact=ARCHIVE successor=ARCHIVE` in the process-local GPU
environment. The confirmation uses `serial_build_comparison.py`; all raw reports,
GPU identities, gate outputs and hashes are retained in `GRADUATION_EVIDENCE.json`.
The new compact diff is the adaptation retained in the source; successor caching
remains reproducible with `guarded_successor_experiment.patch`.


## Final deployment

The final combined build is served at `https://claude-laptop.lan:8188/` from
`~/.scratch/eka-benchmark/graduation-compact-build`. Its served WASM hash matches
the hash above and the exact tested archive. Reload an existing browser session
to load it. `build-wasm` contains the same game binary, with deferred exits ON
and code versions/lifecycle OFF. The original `wasm-port` branch remains the
single checkout; nothing was pushed.

The actual HTTPS launcher passes secure-context/cross-origin isolation, automatic
startup, keyboard/touch delivery, narrow layout and shutdown. All 12 additional
canvas samples have nontrivial visible content (216–284 unique colors), with no
page/request/HTTP errors. This follow-up does not explain the single black
intermediate screenshot in the two-minute run; no flicker-free guarantee is made.
An initial added capture check failed in the test script because pngjs needs a
Buffer, not Puppeteer's Uint8Array; converting the buffer and rerunning passed.
No emulator change was needed for that harness fix. A separate remote LAN device
was not tested. Audio quality remains deferred.
